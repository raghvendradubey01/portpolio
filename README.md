# Raghvendra Dubey — Cyber-3D Developer Portfolio
# Live Site
https://raghvendradubey01.github.io/portpolio/

An interactive, Cyber-3D HUD personal developer portfolio built for Raghvendra Dubey — B.Tech Computer Science Engineering student (Class of 2028) at United College of Engineering and Research, Prayagraj, focusing on AI/ML, Agentic AI, and Full Stack Development.

# Features
> 3D WebGL Cyber Environment (Three.js): Interactive perspective grid floor, floating cyan/violet particle field, and wireframe city towers that respond to cursor movement and active HUD sections.

> Modular Cyber HUD Views:

CORE: Hero HUD with rotating role indicator, GitHub profile avatar sync, and quick actions.

BIO ROOM: Multi-screen interactive bio covering background, journey, vision, and core focus.

3D ORBIT SKILLS: Filterable skill nodes across Programming, Frontend, Backend, AI & ML, and Tools & Platforms.

CYBER CITY: Clickable flagship project cards linked directly to GitHub repositories, plus an architecture inspection modal.

TIME WARP: Chronological timeline of education, product engineering, hackathons, mentorship, and open source.

HOLO HQ: Live GitHub API integration displaying real public repositories and recent activity without fabricated metrics.

CONTACT: One-click email copy, social links, and a validated contact form.

Interactive AI Terminal (RD.OS): Built-in command modal supporting help, whoami, skills, projects, github, contact, and clear.

Single-File Configuration: Centralized portfolioConfig object for updating personal details, projects, skills, experience, resume path, and social links.

# Tech Stack:

3D & Graphics: Three.js (r128)

Styling: Tailwind CSS

Icons: Lucide Icons

Typography: Orbitron, Inter, JetBrains Mono

APIs: GitHub Public REST API (api.github.com)

# Customization:

All personal information, social links, skills, projects, and timeline entries live inside the portfolioConfig object in index.html:

profileImage: Defaults to https://github.com/raghvendradubey01.png

resumePath: Set to your hosted PDF path to enable direct resume download

projects: Add or edit project entries, tech stacks, and repoUrl links

# Local Preview & Deployment

Clone the repository:

git clone https://github.com/raghvendradubey01/portpolio.git
cd portpolio


Open index.html directly in any modern browser or serve it locally:

npx serve .


Push changes to main to auto-deploy via GitHub Pages.
